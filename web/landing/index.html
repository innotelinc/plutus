Shopping, auto-generated in video.

PLUTUS is a self-hosted AI shopping channel: a viewer submits a product URL and an AI host presents it in a generated video clip. Scriptwriting and keyframe generation run through OmniRoute; ffmpeg interpolates between keyframes. No external video APIs, no vendor lock-in, no cloud account required.

Generated video, from a URL.

PLUTUS turns a product URL into a short video clip — an AI writes the script, generates keyframes, and ffmpeg smooths them into motion.

The stack.

A Next.js frontend, a self-hosted Convex backend with ffmpeg, and OmniRoute for AI — all containerized.

Web UI

Convex backend

AI gateway

OmniRoute fronts all AI providers — scriptwriting and keyframe generation.

Video pipeline

T2I keyframes + ffmpeg minterpolate = smooth motion between generated frames.
